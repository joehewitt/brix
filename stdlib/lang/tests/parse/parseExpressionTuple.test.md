# Expression tuple

```brix
(main
  1
)
```

```output
<Integer value="1"/>
```

```brix
(main
  (tuple 1 2)
)
```

```output
<Tuple>
    <Integer value="1"/>
    <Integer value="2"/>
</Tuple>
```

```brix
(main
  (tuple 1 2 3)
)
```

```output
<Tuple>
    <Integer value="1"/>
    <Integer value="2"/>
    <Integer value="3"/>
</Tuple>
```
