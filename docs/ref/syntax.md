I made several unsual choices for UBrix's syntax:

1. Significant dividers
2. kebab case identifiers
3. Mandatory identifier case
4. Mandatory whitespace around operators
5. Function bodies always flush
6. One argument per line
7. Prefer symbols over keywords
8. Expression functions
9. Prepositional arguments
10. Named infix operators
11. Parameterized types with apostrophes

Interesting features:

1. Lazy variables
2. Stream pipelines
3. Grammars (PEG)
4. Stream generics
5. Probes
6. Units

Interesting back-end features:
1. Override GC with manual memory management
2. SoA Tables
3. Green threads and real threads

Interesting front-end features:
1. Markup
2. Stylesheets
3. Events
4. State machines
5. Templated string functions
