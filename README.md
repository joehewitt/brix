# Brix
Brix is an experimental programming language by Joe Hewitt.  See [the language reference](docs/ref/README.md).

Install
-------

```bash
curl -fsSL https://brix-lang.com/install.py | python3 -
```

Brix runs on Apple Silicon Macs with macOS 15 or later, and on aarch64 Linux with glibc 2.34 or
later.
